# Call-centre-analytics-dashboard
Interactive Excel dashboard for analyzing call centre performance, customer ratings, call trends, representative performance, revenue, and regional call activity.
## Project Overview
The Call Centre Analytics Dashboard is an interactive Excel-based data analytics project designed to analyze call centre performance and provide meaningful insights into calls, revenue, call duration, customer ratings, representatives, and regional performance.The dashboard transforms raw call centre data into an interactive visual report using charts, KPI cards, PivotTables, slicers, conditional formatting, and other Excel data-analysis features.The main objective of this project is to help management quickly understand call centre performance and identify trends, high-performing representatives, customer satisfaction levels, and revenue contribution.
## Objectives
The key objectives of this project are:
* Analyze the overall number of calls handled.
* Track the total revenue/amount generated.
* Analyze total call duration.
* Measure average customer ratings.
* Identify the number of 5-star calls.
* Analyze monthly call trends.
* Compare male and female callers across locations.
* Analyze customer ratings from 1 to 5.
* Compare call volume across representatives.
* Compare revenue generated by representatives.
* Analyze regional and customer-level performance.
* Provide an interactive dashboard for business decision-making.

## Business Value
This dashboard can help call centre management:
* Monitor overall performance.
* Identify high-performing representatives.
* Identify representatives with lower workloads or revenue.
* Understand customer satisfaction.
* Identify busy days and months.
* Analyze regional performance.
* Track revenue generated through calls.
* Make better staffing and resource allocation decisions.
* Quickly monitor important KPIs from a single dashboard.
